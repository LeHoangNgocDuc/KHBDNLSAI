DEPLOY TO EXISTING VERCEL URL
1. Extract the full ZIP package.
2. Replace files in the root of your existing GitHub repository with files
   from the extracted smart-khbd-ai directory. Keep the directory structure.
3. Commit your changes. Vercel normally starts a new deployment automatically.
4. Reload the existing web page (Ctrl+Shift+R on Windows).
5. Confirm the footer says Smart KHBD AI 1.0.1.
6. Open Settings, re-enter API keys and choose automatic routing.
7. Click Test for a key, or start analysis to auto-discover Gemini models.

DO NOT upload the ZIP file itself into the GitHub repository as a substitute
for extracting its source files.
